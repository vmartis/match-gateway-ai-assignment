## Where I deliberately did not rely on AI
- Build files generated by start.spring.io, not written from memory; every Boot 4 class/package checked in the jars with `javap` before use (step 1a).
- Gradle distribution checksum taken from the raw bytes served by downloads.gradle.org, not from a model summary (step 1a).
